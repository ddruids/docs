## Primary Font

**Bricolage Grotesque** is our primary typeface and anchors the product experience. It is clear, direct, and approachable.

## Secondary Font

**Aeonik Fono** is dedicated to numbers, balances, prices, and performance metrics. Its structure ensures consistent character width, making data easier to compare at a glance.

## Font families

| Token | Value | Usage |
| :-- | :-- | :-- |
| `font/family/base` | Bricolage Grotesque | All UI copy — headings, body, buttons, links |
| `font/family/display` | Bricolage Grotesque | Same face as base; used at display sizes |
| `font/family/mono` | Aeonik Fono | Numeric display (prices, amounts, balances, addresses) |

## Rules

- Use predefined text styles only, no raw sizes/weights in components
- Headings and display numbers use tight tracking (0); smaller text opens up to 2% for legibility at size
- Use `Number` styles for any monetary amount, balance, address, or quantity, never Body
- Limit the number of text roles on a single screen
- Don't override line height unless necessary
