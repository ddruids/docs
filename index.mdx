## How to use this documentation?

This system is split into focused docs so you can find what you need without reading the whole library.

1. **Designing a new feature?** Start with `foundations.md` and `principles.md`, then pull tokens from `/tokens` and component specs from `/components`.
2. **Implementing in code?** Start with `/engineering` Tailwind config, CSS variables, theming, and implementation rules.
3. **Writing UI copy?** Read `content-strategy.md`.
4. **Animating something?** Read `motion.md`, then `tokens/motion-tokens.md`.
5. **Working with AI on design tasks?** Read `/ai`.
6. **Proposing a change?** Read `governance.md` and `contribution-guide.md`.

| Template | Use |
| :-- | :-- |
| **Design tokens** | Documenting specific design attributes — colors, shadows, radii, and so on. |
| **Typography** | Documenting the type stack you’re using. |
| **Component overview** | Displaying an overview of all the components in your design system, with links to either Figma, or pages in your documentation, or both. |
| **Component detail** | Documenting a component (or set of components) — buttons, input fields, modals, popovers, and so on.You can duplicate any of these templates, and fill them with your own content, or siply overwrite what's already in there if you only want to use them once. |
